# Kebijakan Privasi — Ome TV: Teman Nonton

Berlaku sejak 16 November 2026.

## Data dalam aplikasi

Ome TV: Teman Nonton tidak mengumpulkan atau mengirimkan data pengguna kepada pengembang. Aplikasi tidak menggunakan akun, iklan, pelacakan, analitik, atau server milik pengembang.

Judul film dan serial, genre, durasi, penilaian, catatan, dan tanggal selesai ditonton disimpan di penyimpanan aplikasi pada iPhone. Data ini digunakan untuk daftar tontonan, pemilihan tontonan, dan jurnal pribadi.

## Cadangan dan penghapusan

Data aplikasi dapat disertakan dalam cadangan perangkat sesuai pengaturan iOS. Cadangan tersebut dikelola melalui layanan dan pengaturan sistem Apple, bukan server Ome TV.

Kamu dapat menghapus judul dari koleksi di aplikasi. Menghapus aplikasi akan menghapus penyimpanan lokalnya; pengelolaan cadangan dilakukan melalui pengaturan perangkat atau layanan cadangan yang digunakan.

## Pihak ketiga dan dukungan

Aplikasi tidak menyertakan SDK analitik atau periklanan pihak ketiga. Halaman bantuan ini dihosting di GitHub. Jika kamu membuka halaman GitHub atau mengirim laporan dukungan, penggunaan situs tersebut mengikuti [kebijakan privasi GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Laporan dukungan di GitHub bersifat publik. Jangan menyertakan informasi pribadi atau rahasia dalam laporan.

## Kontak

Untuk pertanyaan mengenai aplikasi atau privasi, [hubungi dukungan Ome TV](https://github.com/ApprenticeTunnel/ome-tv-support/issues/new).

## Perubahan

Kebijakan ini dapat diperbarui jika fungsi atau praktik data aplikasi berubah. Tanggal berlaku di atas menunjukkan pembaruan terakhir.
