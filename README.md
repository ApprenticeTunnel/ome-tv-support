# Ome TV: Teman Nonton

Dukungan untuk aplikasi perencana tontonan di iPhone.

## Bantuan

- **Menambahkan judul:** pilih tombol tambah, isi judul, genre, dan durasi, lalu pilih **Simpan**.
- **Memilih tontonan:** buka **Malam ini**, pilih genre dan waktu yang tersedia, lalu pilih **Pilih tontonan**.
- **Serial:** masukkan durasi satu episode. Waktu dalam jurnal juga dihitung per episode.
- **Riwayat:** buka judul di koleksi dan pilih **Tandai selesai**. Penilaian dan catatan dapat diubah di halaman judul.
- **Penyimpanan:** koleksi tersimpan di iPhone. Aplikasi tidak memiliki akun atau sinkronisasi sendiri.

## Hubungi dukungan

[Kirim pertanyaan atau laporan masalah](https://github.com/ApprenticeTunnel/ome-tv-support/issues/new).

Sertakan versi iOS, versi aplikasi, serta langkah untuk mengulangi masalah. Laporan GitHub bersifat publik; jangan sertakan kata sandi, kunci API, atau data pribadi.

[Baca kebijakan privasi](PRIVACY.md).
